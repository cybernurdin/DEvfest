# Creative direction

Use the product's audience and main action to choose a distinctive, coherent direction. If the brief is open, propose up to three concrete directions with differences in typography, composition, imagery, and tone; select a reasonable direction and continue unless a user choice is essential.

For implementation, carry one visual idea through the full experience: hierarchy, navigation, empty states, copy, and motion. Use realistic content instead of repetitive placeholder cards. Preserve the user's brand and provided assets. Avoid fabricated testimonials, customer logos, or product claims.

Motion should explain state changes or guide attention. Prefer lightweight CSS transitions and respect reduced-motion settings. Ensure the experience remains usable without animation. Add heavy effects or animation libraries only when their benefit justifies the cost.

Use existing assets and CSS/SVG when suitable. Use image generation only when an available tool and the user's task justify a bitmap asset. Record the source and licensing constraints of external assets; do not invent attribution. Translate references into the project's Angular stack rather than copying framework-specific code blindly.

Inspect the implemented result at mobile and desktop sizes. Judge whether the intended mood survives realistic text and states. Report the chosen direction and the working result; do not substitute a concept description for a requested implementation.
